## Способ

Новый root commit, затем по одному merge commit с оригинальной main-веткой каждого проекта
в качестве второго родителя (`--allow-unrelated-histories -s ours --no-commit`). Дерево проекта
помещено под префиксом через `git read-tree --prefix=apps/<name>/ -u <source>/main` перед commit.
Точные SHA, авторство, даты и сообщения исходных коммитов остались прежними. Squash и filter-repo
не использовались. Деревья в import commits побайтно соответствуют исходным trees.

До import commits файлы исторически находятся в корне своего проекта. Для просмотра старой
истории используйте `archive/atlas/main` или `archive/crm/main` и исходные пути; обычный
`git log apps/atlas/...` не гарантирует автоматического прохода через перенос префикса.

## Сохранность оригиналов

Исходные GitHub-репозитории не изменялись. Работа велась в новых зеркалах и новом каталоге.
Локальный Atlas не переключался и не сбрасывался. Обнаруженный локальный Customers-CRM
относится к другому upstream (не Vardahei_CRM_V2); его четыре локальных коммита не импортированы
и сохранены на месте. Состояния HEAD, refs, origin и working tree исходных локальных каталогов
сравниваются до и после операции вне публикуемого репозитория.

Архивные ветки — контрольные точки, их нельзя продвигать или переписывать.
Дальнейшая разработка ведётся на ветках от Parasol main. Изменения после импорта видны обычным
Git diff относительно import commits; исходные проекты остаются самостоятельными.
