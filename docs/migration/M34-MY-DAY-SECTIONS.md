# M34 — прямой доступ к разделам «Моего дня»

Локальная ветка fix/my-day-sections от 3756073, в отдельной рабочей копии Parasol.
Длинный обзор Atlas оставлял назначенную работу ниже первого экрана. В начале страницы
добавлены ссылки My tasks / Technical attention · Atlas; порядок самих блоков сохранён.
Для перехода к своей работе достаточно выбрать ссылку, без ручной прокрутки длинного
обзора. Это число действий в проверенном сценарии, не измерение человеческой экономии времени.

Ссылки видны только вместе с соответствующими разрешёнными блоками. Нет ActivitiesRead —
нет ссылки на задачи; для Atlas нужны одновременно CustomersRead и AtlasRead. Ошибка
чтения остаётся в соответствующем блоке. Ссылка не утверждает, что данные уже доступны.
Новых запросов, команд, провайдеров, прав или production dependencies нет.

Раздел задаётся ?section=tasks или ?section=attention. Это существующая SPA-навигация
AppLink с сохранением остальных query-параметров. Неизвестные значения не используются
как DOM selector. Модель входа сохраняет path+search, поэтому параметр сохраняется при
возврате из входа; проверяется реальный локальный Development redirect, не рабочий Entra.
Прототип с hash прошёл свои проверки, но чтение loginUrl выявило потерю hash при входе;
финальная версия сохраняет query без изменения общего клиента или авторизации.
Известный fragment добавляется из разрешённого значения section для штатного
ScrollRestoration. При первом входе запись default заменяется уникальной записью history,
чтобы прокрутка к задачам не становилась сохранённой позицией следующей главной страницы.
Нормализация не меняет историю возврата и не перехватывает последующий Skip to content.

Переход фокусирует свой блок, оставляя заголовок ниже закреплённой панели. Back возвращает
фокус к ссылкам только при возврате в запомненный адрес начала перехода. Повтор рендера
или смена постороннего query-параметра не перехватывает фокус. Исходные Task/Atlas GET не
повторяются при движении между разделами; прямой новый вход заново читает свои данные.

Браузеры воспроизвели поздний сдвиг: при прямом входе фокус уже находился в задачах, но
загрузка Atlas выше блока уводила его за экран. ResizeObserver теперь следует за размером
общей колонки, пока блок удерживает исходный фокус. Wheel, touch, pointer, key либо
смена фокуса немедленно прекращают выравнивание. Cleanup отключает observer/listeners,
а уже запланированный callback не возвращает фокус или прокрутку в прежний раздел.
Нет таймеров, перехвата пользовательского ввода или повторов запросов.

Новые подписи переведены на nb/en/ru. Сервер, Atlas, контракты и инфраструктура не менялись.
