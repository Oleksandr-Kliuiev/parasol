## Временная проверка переноса

`npm run test:atlas` запускает **все** исходные unit test files. Runner проверяет полный итог,
отсутствие отменённых тестов, ожидаемый exit code, точные имена и диагностические признаки
каждого известного сбоя. Новые ошибки завершают job с ошибкой. В GitHub публикуется warning
и явный список наследованных ошибок в summary; `continue-on-error` не используется.

Исключение разрешено только пока весь Atlas совпадает с исходным tree, включая отсутствие
локальных изменений и новых неигнорируемых файлов. Поэтому оно не может автоматически
перейти на изменённый код следующего этапа. `npm run test:atlas:strict` всегда доступен и
сохраняет обычный ненулевой exit code при этих сбоях.
