## История

### Строгие тесты прежнего сервиса интеграций — 16 октября 2026

Отдельная ветка исправления убрала механизм допуска наследованных ошибок прежнего сервиса: его полные unit,
PostgreSQL и браузерные наборы требовали ноль failures, skips, cancellations и todos и прошли (unit 694/694,
PostgreSQL 781/781, браузер 90/90). CRM в этом исправлении не менялся. В M38 сервис удалён; полный текст этого
раздела — `git show 73c0158:docs/migration/VERIFICATION.md`.

Блокеры полной приёмки M03 на тот момент:

1. GitHub Actions **не исполнил ни одного шага**. Первый [run](https://github.com/Oleksandr-Kliuiev/parasol/actions/runs/38879607137)
   отклонён инфраструктурой GitHub: недавние платежи аккаунта не прошли либо нужно увеличить spending limit.
   Настройки оплаты и лимитов не менялись. После исправления владельцем можно запустить Parasol CI через
   `Actions → Parasol CI → Run workflow` (workflow_dispatch уже настроен).
2. Наборы прежнего сервиса (unit, браузер, PostgreSQL) имели унаследованные сбои; они исправлены отдельной веткой
   16 октября 2026 (раздел выше), а сам сервис удалён в M38.
3. Coverage gate CRM настроен по исходному workflow; локальный интеграционный прогон выполнен без
   coverage instrumentation. Численные coverage thresholds на Linux пока не подтверждены.

GitHub green CI и готовность к deployment **не подтверждены**. Созданные для этой проверки контейнеры баз данных
остановлены и удалены; существующие контейнеры и базы пользователя не изменялись.
