Воспроизвести структурную проверку из корня полного репозитория:

```sh
python3 docs/claude-opus/validate-package.py --next
```

Проверка допуска `--release` намеренно возвращает ошибку до выполнения всех задач и внешней приёмки. Скрипт не запускает тесты приложения, не обращается в сеть и не изменяет файлы. Корректность записанного evidence проверяет reviewer.

ZIP рядом с папкой содержит снимок пакета, CLAUDE.md и исторический аудит с доказательствами. В архиве сохранены пути от корня; приложение не включено. При переносе сопоставлять с актуальной рабочей копией, не перезаписывать новый прогресс старым архивом. Исторический аудит содержит ссылки на исходную абсолютную рабочую папку; переносимые ссылки для исполнения находятся в карточках пакета.
