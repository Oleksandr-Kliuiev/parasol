# DEV-13 Режим обслуживания и восстановление

Приоритет: **P1**. Аудит: **A12**.

Зависимости реализации: DEV-04, DEV-06, DEV-07, DEV-11. Проверки: Q1, Q2, Q4.

Внешняя приёмка: EXT-04.

## Контекст

Runbook останавливает worker, но оставляет web-пути записи. Имена ресурсов расходятся с Bicep. Restore может повторить внешние эффекты.

## Результат

Восстановление останавливает все записи и отправки, сохраняет доказательства внешних эффектов и имеет измеренный RTO/RPO.

## Объём реализации

1. Добавить явный режим maintenance/read-only с контролем во всех репликах и состоянии вне восстанавливаемой бизнес-базы либо эквивалентной гарантией. Управление доступно ограниченному оператору.
2. Охватить mutation API, imports, Hangfire dashboard/trigger, jobs, outbound, OIDC user provisioning и прочие скрытые записи. Режим действительно read-only, а не только спрятанные кнопки.
3. Обнаруживать реальные имена Azure-ресурсов из deployment outputs/config; убрать фиктивные команды остановки и проверить поддерживаемый механизм для Container Apps.
4. Восстанавливать в изолированную новую базу/окружение. Проверять схему, audit, charges, документы/blob, DataProtection/key access и интеграционные курсоры.
5. Перед возобновлением worker сверять внешние заказы/письма/встречи после точки восстановления; неоднозначные эффекты карантинировать. Применять выполненные privacy-действия из DEV-11.
6. Обновить runbook с dry-run, prerequisites, контрольными точками, таймерами, abort/cutback и ответственными Finance/оператора. Отдельно покрыть региональный сценарий и потерю файлов/ключей.

## Критерии приёмки

- **DEV-13-AC01** — Все обычные пути записи в maintenance отклоняются предсказуемо; read API работают там, где база доступна.
- **DEV-13-AC02** — Ни одна replica/worker не продолжает отправку из-за stale cache переключателя.
- **DEV-13-AC03** — Скрипт не выбирает prod по умолчанию и не переименовывает/удаляет исходную базу без выбранной операции.
- **DEV-13-AC04** — После restore повторная обработка не создаёт новый заказ с уже существующим внешним эффектом.
- **DEV-13-AC05** — На учении приложены timestamps: RPO ≤ 1 ч, RTO ≤ 4 ч; если не выполнено, gate отмечен failed.
- **DEV-13-AC06** — Обнаруженные дефекты runbook исправлены по результату учения, а не только компиляции Bicep.

## Данные и обратимость

Режим обслуживания не должен зависеть от незавершённой миграции той же базы. Сохранять исходную БД и возможность безопасного обратного переключения до окончательной приёмки; повторная отправка только после сверки.

## Границы

Локальный тест не заменяет облачное учение EXT-04. Не восстанавливать/останавливать реальные среды по умолчанию.
