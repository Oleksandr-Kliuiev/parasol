# Известные ограничения (DEV-23)

Сводка собрана из разделов «Самопроверка и остаточные риски» / «Не сделано» всех `docs/claude-opus/evidence/DEV-00.md … DEV-22.md`, из `docs/claude-opus/PROGRESS.md` (блокеры), `docs/claude-opus/external-gates.json`, `evidence/DEV-21/deferred-and-accepted.md` и `docs/adr/ADR-024-cryptographic-inventory.md`. Проверка выполнена чтением этих файлов и сверкой с кодом там, где это указано в колонке «Источник».

Правила таблиц:
- Колонка «Владелец (роль)» **пуста намеренно**: владельцы не назначены, имена и роли здесь не придумываются. В «Ждёт» указан gate (`EXT-xx`) или решение (`DEC-xx`), от которого зависит снятие ограничения; пустое значение означает, что отдельного gate нет.
- «Обходной путь» — только то, что описано в runbooks или evidence; где процесса нет, записано «нет».
- Ограничение не закрыто и не принято, пока владелец не записал решение `DEC-EXC-<номер>` с датой окончания (формат — `evidence/DEV-21/deferred-and-accepted.md`, runbook 17). Такие записи на момент составления отсутствуют.
- Файл ничего не переводит в `accepted`: все карточки DEV-00…DEV-22 остаются `code_verified` или `blocked` по `PROGRESS.md`.
