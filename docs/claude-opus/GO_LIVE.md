## Досье конкретного релиза

При DEV-23 заполнить: commit и clean/dirty state, source manifest, digests web/worker, SBOM/scanner reports, конфигурация без секретов, список миграций, совместимость и rollback, release notes, acceptance evidence, открытые ограничения с владельцами, runbook ссылки, target environment, окно выпуска и решение go/no-go с датой и лицами.

Запуск запрещён при открытом P1 в запускаемом объёме, необъяснённом финансовом расхождении, непроверенном восстановлении, неподтверждённом record scope, незакрытом применимом gate или критической/высокой security находке. P2 из этого пакета также входят в заявленную полноту CRM; перенос возможен только явным изменением scope с сохранённым ограничением, не путём автоматической галочки.

Ограниченный rollout начинать только после допуска. Сначала согласованная группа пользователей/клиентов, затем расширение по наблюдаемым критериям. До выпуска определить численные пороги ошибок/задержек, владельца остановки и длительность наблюдения. Ошибка доступа, двойное начисление, потеря документа или неизвестный внешний эффект требуют остановки соответствующей функции, сверки и решения владельца.

Rollback binary не отменяет счета, миграцию данных или изменения у поставщиков. В досье должен быть конкретный cutback/reconciliation plan. Команда разработки не подписывает за Finance и владельца продукта. Инструкция реализации не является разрешением на фактический production deployment.
