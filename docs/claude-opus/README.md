# Пакет разработки для Claude Code Opus

Версия: **1.0 · 03.10.2026**. Репозиторий: Vardahei CRM v2. Цель: довести существующий продукт до надёжной корпоративной CRM к концу 2026 года по направлению [аудита](../10-audit-2026-10-03.md). Это пакет реализации и приёмки; доработки ещё не выполнены.

Сохранить модульный монолит, React/Fluent UI, Entra BFF и разделение ответственности CRM / Atera / PowerOffice. Приоритет — правильные деньги, доступ, документы, восстановление и проверяемый выпуск; затем полнота ежедневных сценариев и подтверждение масштаба. Переписывание продукта и переход к микросервисам не входят в план.

## Как начать

1. Открыть **полный репозиторий** в Claude Code и выбрать Opus доступным в вашей установке способом. Архив пакета содержит документацию, не исходники приложения.
2. Передать Claude текст из [START_HERE.md](START_HERE.md). Он поручает реализацию, проверки и ведение прогресса, начиная с DEV-00.
3. После перерыва передать тот же текст: Claude сначала прочитает актуальные статусы и продолжит незавершённую работу.
4. Проверять результаты по evidence и критериям, а не по количеству созданных файлов. Для действий в реальных средах используется отдельный допуск с указанной средой и объёмом.

## Что означает готовность

`code_verified` подтверждает локальную реализацию и проверки; `accepted` дополнительно требует всех критериев и внешних gates карточки. Отсутствие доступа к sandbox не останавливает независимые локальные задачи, но не превращается в успешную интеграционную приёмку. Все задачи сейчас `todo`, внешние условия `not_run`.

Технический baseline: OWASP ASVS 5.0.0 L2, WCAG 2.2 AA, практики NIST SSDF и согласованные эксплуатационные SLO. Это целевая программа, а не заявление о сертификации. Изменения стандартов после 03.10.2026 не предсказаны: перед выпуском сверить официальные источники из VALIDATION.

В подготовке пакета проверены структура, ссылки, зависимости и покрытие аудита. Приложенные [результаты аудита](../audits/2026-10-03/validation.txt) относятся к исходному коду на дату аудита и не подтверждают будущие изменения.
