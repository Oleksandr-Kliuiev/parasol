# Parasoll UX-демо

Кликабельный прототип нового интерфейса Parasoll на синтетических данных. Обоснование решений —
в [UX-концепции](../UX-CONCEPT.md). Сервер, база и рабочие источники не нужны; продакшн-зависимостей нет.

Демо говорит словарём M38 ([«Drift» в CRM](../../migration/M38-OPERATIONS-IN-CRM.md)): вкладка клиента
«Drift», очередь «Varsler», прямые интеграции CRM на «Tilkoblinger»; обзор Microsoft 365 убран целиком.
Huntress показан в целевом состоянии (M41), CloudAlly — как ещё не подключённый (M42).

## Как открыть

- Двойной щелчок по `index.html` — демо работает прямо из файла (обычные скрипты, без модулей).
- Или через любой статический сервер из этой папки, например:

```bash
python3 -m http.server 4173 --directory docs/ux/demo
```

Шрифты Manrope и Onest загружаются с Google Fonts; без сети используются системные шрифты.

## Что попробовать

- Роль, язык (NB/NN/EN, по умолчанию NB), тема и плотность — в меню профиля внизу боковой панели
  (на телефоне — вкладка «Ещё»). Роли: Ingrid (техник), Jonas (руководитель сервиса), Anna (администратор и финансы).
- «Varsler» → «Tildel» у критического оповещения: тема задачи берётся из заголовка оповещения, её можно
  поправить; у Eikeli коллега успел раньше — дубль не создаётся. У задачи кнопка «Kilde» открывает оповещение;
  закрытие оповещения не закрывает задачу, и наоборот.
- Карточка клиента → «Drift»: сводка, оповещения, устройства с числом открытых оповещений.
  У Trollvik нет связи с клиентом Atera — видно, почему пусто и кто это исправляет.
- «Tilkoblinger»: включена ли интеграция, последний успешный запуск каждой синхронизации, ответ фоновой службы.
- Задача Nordlys: измените срок и сохраните — откроется конфликт правок с сохранённым черновиком.
- ⏱ у задачи → форма часов с подставленными клиентом и заявкой; без описания оплачиваемая запись не сохранится.
- Jonas → «Время» → «Утверждение»: снимите одну запись и утвердите остальные.
- Anna → «Мой день» → просроченный счёт → «Задача: напомнить клиенту».
- ⌘K / Ctrl K → «reception»: два устройства с одинаковым именем у разных клиентов.

Горячие клавиши: `/` или Ctrl K — поиск, `N` — новая задача, `T` — записать время,
`G` затем `D`/`A`/`C`/`V`/`T` — переходы, `?` — список клавиш. Все изменения живут только в открытой вкладке.

## Устройство

| Путь | Назначение |
| --- | --- |
| `css/tokens.css` | Цвета, шрифты, отступы и радиусы для светлой и тёмной темы |
| `css/base.css`, `shell.css` | Сброс, типографика, боковая панель, верхняя панель, нижние вкладки |
| `css/components.css`, `lists.css`, `forms.css`, `overlays.css` | Компоненты |
| `css/views.css`, `pages.css` | Раскладки экранов |
| `js/core.js` | Шаблоны с экранированием, состояние, маршруты, форматирование по Осло |
| `js/i18n.js`, `js/locales/*` | Строки NB, NN, EN (по три файла на язык) |
| `js/data-core.js`, `data-work.js` | Синтетические клиенты, устройства, оповещения, задачи, часы, счета, состояние интеграций |
| `js/model.js` | Производные выборки и имитация записей (назначить, закрыть оповещение, завершить, утвердить) |
| `js/ui.js`, `rows.js`, `charts.js`, `overlays.js`, `shell.js`, `palette.js` | Общие элементы |
| `js/flow-*.js` | Оповещение и назначение, задача и конфликт, запись времени |
| `js/views/*` | Экраны |
| `tools/*` | Проверки |

## Проверки

```bash
node docs/ux/demo/tools/check-locales.mjs
```

```bash
node docs/ux/demo/tools/smoke.mjs
```

`check-locales` сверяет ключи трёх языков. `smoke` поднимает свой сервер и в Chromium проверяет
сценарии, клавиатуру и axe (WCAG 2.2 AA) в обеих темах; нужны установленные зависимости
`apps/crm/web` (`npm ci`) и браузер Playwright. Аудит вёрстки — навыком `ui-layout-audit`
на ширинах 1440, 768, 390 и 320 px.

## Ограничения

- Данные выдуманы; совпадения с реальными компаниями случайны. Перезагрузка возвращает исходное состояние.
- Внешние ссылки (Atera, Huntress, PowerOffice), скачивание PDF и отправка в PowerOffice в демо не выполняются.
- «Les på nytt» перечитывает сохранённые данные; синхронизацию с источниками делает фоновая служба, в демо её нет.
- «Продажи», «Проекты», «Отчёты» и «Администрирование» показаны упрощённо.
- Значки повторяют геометрию Lucide (лицензия ISC).
