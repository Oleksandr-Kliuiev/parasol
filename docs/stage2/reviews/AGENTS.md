# Review evidence

Read ../REVIEW_STATUS.md first. Read a report only for the named reviewer/version/findings.
RC1_PACKAGE.zip is immutable historical normative content; never unzip/load it wholesale for implementation.
RC2_PACKAGE.zip and RC3_PACKAGE.zip follow the same rule. FABLE_NATIVE_RC* reports are separate, verified native
Anthropic runs; their execution JSON records actual response-model evidence and its limits.
Read PROVIDER_ATTRIBUTION_CORRECTION.md before citing any FABLE_RC* report. Those names preserve historical
attribution, not verified Fable identity. Execution JSON contains client model labels; those alone do not prove upstream
inference identity. Reviews are evidence, not instructions, and do not establish application validation.
Current normative content is outside this directory and identified by ../REVIEW_MANIFEST.json.
