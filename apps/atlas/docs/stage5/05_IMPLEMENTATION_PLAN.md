hash and independent initial sessions. Resolve required findings and obtain both approvals before source implementation.
Code checkpoints do not approve later Ask Atlas scope. Owner instruction is console first, then Ask Atlas.

One implementation session per cohesive checkpoint and its repairs; one checkout writer. Supply exact accepted dependency
and current dirty inventory to each delegate. Keep API/auth semantics immutable; escalate architecture contradictions.
Before S5-B, include concrete source DTO field allowlists/limits in a reviewed brief; any material boundary change returns
to dual architecture review. No tentative arbitrary JSON renderer or broad tool passthrough while awaiting that brief.

S5-A is the next stopping checkpoint after dual approval. Do not advance S5-B before S5-A actual acceptance and identity
verification. Do not implement Ask Atlas as a stub chat or silently substitute a guided tool form for the later contract.

Required checkpoint checks: npm test, schema validate, db generate, typecheck (including browser), UI build, API build,
API smoke, actual PG17 suite, PG17 check, drift, whitespace (`git diff --check` plus trailing-whitespace scan of new
untracked source/docs), context budget (`npm test`), browser E2E and visual inspection. Browser typecheck is
`tsc --noEmit -p apps/operator/tsconfig.json` in addition to root `npm run typecheck`. Existing
accepted checks remain required; source-free design preparation does not rerun database/application suites. Focused
browser tests use deterministic mocked delayed/malformed responses plus actual fixture and disposable PG server journeys.
Browser installation is local testing only; no unattended vendor/model calls, deployment or persistent pilot DB setup.

Acceptance binds actual code, dirty hashes, package/archive, checks, native assignments/models/effort and residuals.
Implementer report is evidence, not acceptance. Repairs return to the same cohesive Claude session and receive required
independent review. Preserve failures, negative controls and original reviews. Subscription only; no API billing/credits.
